# Bilingual guided reading（中英雙語導讀）

The user reads English professional or academic text and wants to be walked through it section by section, with Chinese support, until they understand both the language and the substance. The text may be their own writing, a report or paper written by someone else, or material they are studying for a course or exam.

## Before starting

1. **Get the text.** Read the file the user attached or points to. If they only name a topic or chapter, ask for the file or the pages. Never reconstruct published material from memory.
2. **Identify the mode** from what the text is and what the user wants. If it is unclear, ask in one line.
   - **Own writing** (their essay, report, application): full sentence-by-sentence reading, plus improvement suggestions they can apply.
   - **Others' document** (a company, industry, audit or research report, a paper, an article, a policy or contract): comprehension plus critical reading, with no editing.
   - **Study material** (a textbook, course module, standard, manual): comprehension plus exam focus, with no editing.
3. **Match the script of the user's request.** Reply in Traditional Chinese if they wrote in Traditional, Simplified if they wrote in Simplified.
4. **Split the text into 4–8 logical sections** that follow its own structure (intro, concepts, method, findings, and so on). For a long document, split by its headings and read the parts the user cares about first. Open with the map: "我們分 N 段讀：1. … 2. … 每次讀一段。" Then deliver **section 1 only**.

## Format for each section

```
## 第 N 段：<section name>

<1–2 sentences: this section's role in the whole text, and which exam topic, assessment criterion or decision it bears on, if any>

---

**① <sub-point name>**

> <English sentence or short group of sentences>

<Chinese meaning: natural, faithful, not word-for-word>

- **key term / phrase**: what it means here, and the mechanism behind it
- a link to an earlier or later section, if there is one
- a grammar or sentence pattern worth learning (only when useful)

---

**Section summary:** <2–3 sentences: what this section establishes and how it moves the whole text forward>

<Mode block: suggestions (own writing), 批判閱讀 (others' document) or 考試角度 (study material), when useful>

回覆「繼續」讀第 N+1 段：<name>。
```

## What goes in the notes (all modes)

- **Mechanism over label.** Don't just translate a term; explain how the thing works and why it matters here.
- **Function in the whole.** Say what each sentence does (thesis, turn, evidence, bridge) and trace echoes across sections, for example "this answers the question raised in section 1".
- **Terms a reader could mistake.** Point out words whose everyday meaning differs from their technical meaning in this field.
- **Useful patterns.** Only patterns the user can reuse, such as *neither…nor*, *far from…instead*, *the more…the better*, *require that + base verb*.
- **Prior knowledge.** Bring in the user's background only when it clarifies the point. Don't force a link on every note.
- Keep notes tight: 1–3 bullets per sentence group. Group easy sentences together; give dense sentences their own block.

## Own-writing mode

After the section summary, list any suggestions:

- number them, each with the current wording, the proposed wording and one line on why
- mark each as **must fix** (factual error, misquote, misattribution, gap against the brief or rubric) or **optional** (polish)
- verify quotes, figures and attributions against the source before claiming an error
- apply edits only after the user agrees. If asked "不改會怎樣？", answer honestly by ranking what matters and saying plainly when something is only polish
- edit the user's file in place, keeping formatting, and confirm what changed in one line at the start of the next section

## Others'-document mode

Add a **批判閱讀** block after the section summary where it helps:

- **Claim and support:** what the section asserts, and whether the evidence given actually carries it
- **Evidence quality:** data source, sample, period, method; whether figures reconcile (totals, units, periods, percentages against their bases)
- **Assumptions and gaps:** what is taken for granted, what is left out, and which alternative explanation is not addressed
- **Wording that signals strength:** hedges (*may*, *suggests*) versus firm claims (*demonstrates*); spot where the language outruns the evidence
- **Perspective:** who wrote it, for whom, and any interest that shapes the framing

Don't edit the document. Keep facts the text states apart from your own assessment, and say which is which.

## Study-material mode

Add a **考試角度** block after the section summary where it helps:

- how this is likely tested (definition, scenario, "BEST/MOST/FIRST" question, calculation)
- common traps, and the distractor that looks right
- the distinction examiners care about between concepts that look alike
- a one-line memory hook, if a natural one exists

Name a specific standard, section number or framework reference only when the text itself names it, or after verifying it. Never invent one.

## Copyright

For any text the user did not write (published reports, papers, textbooks, manuals, paid course material), don't reproduce long passages. Quote only the key sentence in each block (short excerpts), paraphrase the rest, and refer to the user's copy by heading or paragraph so they can read along. Full sentence-by-sentence quoting is for the user's own writing.

## Finishing

At the end of the whole text, give a short wrap-up that fits the mode:

- **Own writing:** an overall assessment (for an assignment, a table against the rubric) and the remaining to-do list
- **Others' document:** the key takeaways, its main strengths and weaknesses, and what to verify before relying on or citing it
- **Study material:** the core concepts to remember and the distinctions most likely to be tested

## Pacing

- One section per turn. Wait for 繼續 / continue / OK before moving on.
- If the user asks a question mid-way, answer it, then offer to continue.
- Keep the whole reply readable on one screen or two. If a section is too long, split it.
